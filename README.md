# OPE-LIFTS

JOH Opera House, Parts 004 & 005 – OTIS lifts L12, L15–L23: site readiness report for installation handover.

Open `index.html` in a browser. The site checklist, the site status notes and the obstacle status can be edited on the page; on GitHub Pages the changes are kept in the browser of the device used.

- `tracker.html` – site readiness tracker for all 22 Opera lifts, grouped by Part 1–5.
- `otis.html` – OTIS shaft handover tracker (L12, L15–L23) against the OTIS requirements for the vertical measurement.
